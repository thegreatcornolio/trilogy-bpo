# Trilogy GCC website

Focused marketing site for Trilogy as a **Global Capability Centre** provider.

## Run locally

```bash
cd gcc-site
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Brand

- Logo: `public/logo-gcc.png` (Trilogy Global Capability Centre)
- Colours: ink `#0E1B2A`, lime `#2FE85C`, mint `#8CE081`, forest `#0E7C46`
- Fonts: Archivo + IBM Plex Mono
